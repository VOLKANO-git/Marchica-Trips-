# Marchica Trips

A responsive tourism website showcasing activities around the Marchica Lagoon in Nador, Morocco. Visitors can explore local experiences, discover activities, consult frequently asked questions, and access the reservation page.

## Features

- **Home:** Discover Marchica Trips and its tourism experiences.
- **Activities:** Explore kayaking, boat trips, hiking, swimming, fishing, and culinary experiences.
- **FAQ:** Find answers to frequently asked questions.
- **Reservations:** Access the reservation interface.
- **Responsive design:** Designed to adapt to different screen sizes.
- **Accessibility:** Focus on semantic HTML, keyboard navigation, and accessible interfaces.

## Technologies

- HTML5
- Tailwind CSS v4
- Vite


## Installation

Clone the repository and navigate to the project directory:

```bash
git clone <repository-url>
cd Marchica-Trips-
```

Install the project dependencies:

```bash
npm install
```

## Development

Start the Vite development server:

```bash
npm run dev
```

Open the local URL displayed in the terminal, usually `http://localhost:5173/`.

Vite provides automatic page reloading during development. Edit the HTML files and `src/input.css` to update the website.

## Production Build

Generate an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The production files are generated in the `dist/` directory.
